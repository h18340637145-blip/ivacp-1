# 飞书统计身份对齐

本轮目标：恢复参考系统的飞书完整身份统计，避免同号工作项在不同项目或类型中被合并；不调整统计指标或增加产品范围。

- [x] 对照原统计入口、纯函数及加载器，复现本地与团队漏计。
- [x] 先编写失败测试：跨项目、跨类型、重跑、历史、缺快照回退、账号隔离。
- [x] 统一身份提取，IndexedDB 四表只读事务；MySQL 关联最小投影且保留区间外上下文。
- [x] 浏览器验收刷新、查询、非法月份、团队失败重试和复制报告；修复失败时仍可复制旧报告。
- [x] 全量测试、lint、类型检查、独立构建与生产浏览器验收。
- [x] 更新 Harness 文档与会话交接。

边界：不调用真实外部分析或写接口；不修改现存业务数据。缺少快照时按分配身份回退；两者身份均缺失时用分配 ID 隔离，连分配 ID 也缺失的旧记录沿用其 ticketKey，无法还原丢失的项目与类型。

验证结果：294 项测试、8 文件 18 项生产浏览器场景通过；lint、typecheck、独立构建退出 0。独立预览 http://127.0.0.1:3027。
