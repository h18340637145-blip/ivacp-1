# Docupedia 月度上传统计

## 已确认范围

在本地持久记录每个月成功确认上传、正文字符数严格大于 700 的 Docupedia 文本文章数量。采用按月 JSONL 文件，不增加界面、数据库或历史补传。

## 统计规则

- 保存到 `log/docupedia-upload-stats/YYYY-MM.jsonl`，月份取服务器本地时间；`uploadedAt` 为 UTC ISO 时间。
- 对实际文章 `PlannedPage.text.length` 计数，包括空白和分节标题，不包含转义后的 HTML 包装；字符数为 JavaScript UTF-16 代码单元数。
- `created` 和 `existing` 成功后均可记录；同月按唯一标题去重。根页面、目录页面、失败文章及正文长度不超过 700 的文章不计入。
- 每条记录保存 `uploadedAt`、`month`、`title`、`characterCount`、`action` 和 `monthlyTotal`。
- 计数读取已有文件，跨重启续计；历史月份保留，不被 90 天运行日志清理删除。启用前历史不推算，无合格上传时不创建文件。

## 实现与边界

独立记录器负责读取、去重和追加；归档模块仅在文章成功路径调用。当前本地单个 Next.js 进程按文件串行执行，防止并发统计丢失；不支持多个服务进程同时写同一目录。记录失败只告警，不改变分析、上传成功状态或既有重试策略；保留文件由本地文件系统负责，不保证进程崩溃或磁盘故障时的记录恢复。

## 验证

定向测试覆盖 700 / 701 阈值、重复标题、created / existing、并发累计、独立进程续计、跨月文件和清理保留。归档静态守卫确认只在文章成功后记录正文，并保留已有 Docupedia 归档、重试和类型检查。
