# 飞书 MQL 已完成自动分配对账设计

## 背景

飞书项目的自动分配以规则组 MQL 的本次成功查询结果为准。当前实现仅移除未完成的过期自动分配，导致已完成的自动分配在后续 MQL 不再命中时仍显示在规则组中。

## 决策

一次规则组 MQL 查询成功后，对该规则组内所有未再次命中的自动分配解除 `ruleGroupId`，不按处理状态豁免。仅移除其当前自动归属；`MeegleProcessResult`、历史记录和分析产物均不删除。

人工分配继续不受自动对账影响。MQL 查询失败时继续保留既有自动分配，避免把外部查询故障误判为不命中。

## 验收

- 已完成、处理中、待处理和失败的过期自动分配均从成功查询的规则组解除。
- 再次命中的自动分配继续保留。
- 人工分配及查询失败规则组继续保留。
