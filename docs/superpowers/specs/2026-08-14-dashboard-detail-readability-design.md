# 看板与结果详情可读性优化设计

## 背景与目标

Jira 智能票据分析系统采用暗色工业指令台风格，首页规则组看板与 Jira、Meegle
结果详情承载长时间阅读、高频状态判断和人工复核操作。当前页面存在文字层级偏小、
辅助信息与背景对比不足、同类状态表达不一致的问题。

本次优化采用「平衡增强」方案：在不改变任何业务流程、数据模型、接口或路由的前提下，
提升文字可读性、颜色语义和操作层级。

## 范围

### 包含

- 首页统一规则组看板：`KanbanBoard`、`RuleGroupList`、`RuleGroupRow`。
- Jira 分析结果详情：`IssueDetail`。
- Meegle 分析结果详情：`MeegleResultDetail`。
- 上述页面共享的暗色主题文字、表面、边框和状态颜色令牌。
- 小屏幕下的排版收缩与触控目标检查。

### 不包含

- Jira、Meegle 的筛票、处理、复核、回填、自动周期逻辑。
- IndexedDB 结构、后端 API、路由与权限策略。
- 页面信息架构重做、数据字段增删或图表能力改造。
- 新增浅色主题、字体远程加载或新的图标库。

## 视觉系统

保留既有近黑背景和 Amber 主操作色，建立以下稳定的阅读尺度：

| 角色 | 尺寸 | 用途 |
| --- | --- | --- |
| 页面标题 | 22–26 px | 看板、票据或工作项主标题 |
| 区块标题 | 17–18 px | 结论、证据、复核等内容区标题 |
| 行标题 | 15–16 px | 规则组名称、结果卡片名称 |
| 正文 | 15–16 px，行高 1.6–1.7 | 分析结论、说明和人工复核内容 |
| 元信息 | 13–14 px | 来源、时间、车型、角色和配置摘要 |
| 标签与表头 | 不低于 12 px | 状态、表格列头、技术标识 |
| 技术文本 | 13 px | JQL、MQL、路径和标识符，继续使用等宽字体 |

颜色使用语义令牌，而不是在组件中散落新色值：

- 主文本使用高对比浅色，辅助文本使用仍可辨识的蓝灰色。
- Amber 只表示主操作、路径分隔和需要优先关注的提示，不用作普通正文。
- 成功、进行中、失败/驳回和信息来源分别使用可区分的语义前景、弱背景和边框。
- 每个状态始终保留中文文字；颜色不是唯一的信息载体。
- 边框、悬停和键盘焦点使用统一的明度阶梯，避免灰色叠灰色。

## 页面设计

### 首页规则组看板

- 表头提升为 12 px，保持等宽字体与小型大写标识的扫描感。
- 规则组名称提升到 15–16 px、字重为 600 左右；车型、Prompt、来源数量等元信息为 13 px。
- 保持彩色左边条区分规则组，但状态标签使用「文字 + 语义色」组合。
- 主操作按钮与次操作按钮形成清晰层级，交互区满足至少 44 px 的有效点击高度。
- 窄屏时优先保留名称、状态和主操作；配置与次要元信息自然换行，不产生横向滚动。

### Jira 与 Meegle 结果详情

- 两种详情页共享同一套页面标题、面包屑、状态标签、结论卡片和主要操作的视觉规则。
- 票据/工作项标识、来源、规则组和时间采用 13–14 px 元信息层，避免与结论正文竞争。
- 「一致性结论」、人工复核、回填预览等长文本采用 16 px 与 1.65 左右行高。
- 日志路径、JQL/MQL、文件名等技术内容保持等宽字体，并提高到至少 13 px。
- 图表说明、空状态和错误提示使用可读的辅助色；错误信息包含文字原因和恢复操作。

## 实现边界

- 在 `app/globals.css` 中补齐或校正主题令牌、文字层级类和减少动画偏好。
- 仅调整目标组件的样式、语义类名和必要的无障碍属性；不改动 Store 调用、事件处理或 API。
- 复用现有组件与状态文案，不新增跨页面状态管理。
- 所有焦点样式保留可见性；悬停动效限定为 `opacity`、`color`、`background-color` 或 `transform`，并支持 `prefers-reduced-motion`。

## 验收与回归

- 在 375 px、768 px、1024 px 和 1440 px 视口下检查首页、Jira 详情与 Meegle 详情，无横向滚动或内容遮挡。
- 验证正文、元信息、状态标签和主要按钮具有清晰的层级与对比度。
- 验证键盘焦点可见，状态不只依赖颜色，主要操作的有效点击区域不小于 44 px。
- 运行现有 TypeScript、Lint 与项目中的相关 UI 防回归脚本；必要时补充仅验证样式契约的轻量检查。
- 手动验证筛票、处理、复核、回填和刷新后 IndexedDB 数据保留行为未受影响。

## 取舍

不引入新的品牌色或远程字体，避免偏离既有暗色工业指令台和增加加载风险。相比全面重做，
本方案以可读性和可访问性为优先，保留熟悉的行式看板与结果详情结构。
