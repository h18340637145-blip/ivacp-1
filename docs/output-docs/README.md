# Jira 智能票据分析系统文档集

## 术语

| 术语 | 含义 |
|---|---|
| 规则组（RuleGroup） | 一个车型、项目或分析场景的配置单元，包含 JQL、可选 MQL、CAN 配置和 Prompt。 |
| 筛票快照 | 某次筛票成功后保存的候选工单集合，供 Jira 后续处理使用。 |
| 工作项 | 飞书项目中的工单实体；其生命周期与 Jira 工单独立保存。 |
| 运行产物（artifact） | 单次分析在 `log/` 下生成的日志、证据、图表和结果文件。 |
| Step 2 提取信号 | 分析流程中从问题上下文提取且成功映射到车型配置的代表信号；唯一允许进入回放和绘图的数据源。 |
| 回填 | 将经人工授权的分析结论作为评论写回 Jira 或飞书项目，并可执行选定状态流转。 |
